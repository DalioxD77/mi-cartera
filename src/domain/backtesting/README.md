# Backtesting

Esta carpeta queda reservada para la preparación del backtesting futuro.

No se asume que un patrón visual o una señal de gráfico implique necesariamente una estrategia rentable. Los tipos aquí definidos son una base para análisis más formales, validación histórica y comparación contra "comprar y mantener".

Todavía no hay implementación ni simulación operativa.
